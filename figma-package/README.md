حزمة Figma - تعليمات الاستيراد

ما يوجد في هذه الحزمة:
- colors.json: تعريف ألوان المشروع لاستخدامها كـ Color Styles في Figma.
- typography.json: أسماء الخطوط ومقياس الأحجام لتعيين Text Styles.
- assets: الصور الأصلية موجودة في `src/assets/img/` (اسحب وأفلت داخل Figma).

خطوات الاستيراد السريعة:
1. افتح Figma وأنشئ ملفًا جديدًا.
2. استيراد الأصول: اسحب محتويات `src/assets/img/` إلى اللوحة (أو استعمل "File > Place image...").
3. إنشاء Color Styles: استخدم القيم في `colors.json` وأنشئ Color Styles لكل قيمة.
4. إنشاء Text Styles: طبق الخطوط من `typography.json`. إذا لم تكن الخطوط متوفرة محليًا، ثبتها (Google Fonts).
5. إعادة بناء المكونات: استخدم القيم والتخطيطات الموجودة في مكونات `src/components` كمخطط لبناء الإطارات (Frames) في Figma.

خيارات أوتوماتيكية (أحتاج بيانات):
- لإنشاء ملف Figma تلقائيًا عبر Figma API سأحتاج "Personal Access Token" واسم المشروع/الفريق. أرسلها إذا رغبت في إنشاء الملف مباشرةً.

هل تريد أن أجهز ملف Figma تلقائياً (أحتاج توكنك) أم أتابع بتحسين حزمة الاستيراد؟
